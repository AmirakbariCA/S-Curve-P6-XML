# S-Curve Generator for Primavera P6 XML

**Instant Plan vs Actual S-Curve** from Primavera P6 XML export - just drag & drop. 
No installation, P6 license, or Excel required.

## Features
- Drag & drop Primavera P6 XML file
- Instant S-Curve visualization (Planned vs Actual)
- Fully client-side (your data stays private)
- Responsive web interface
- Free & Open Source

## Quick Start

1. Export your schedule as XML from Primavera P6
2. Go to the (https://p6-scurve.netlify.app/)
3. Drag and drop the XML file
4. View your S-Curve instantly
